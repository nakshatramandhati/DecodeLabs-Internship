# Project 3 – AI Recommendation Logic

## Project Description

This project is a simple AI-based movie recommendation system. It takes the user's preferred movie genre and recommends movies that match the selected preference.

## Goal

Create a simple recommendation system based on user preferences.

## Key Requirements

- Take user input such as choices or interests
- Match preferences using logic
- Display recommended items

## Features

- Takes user preference as input
- Supports multiple movie genres
- Matches user preferences using logical conditions
- Displays recommended movies
- Handles unsupported genres

## How It Works

1. The program stores movies with their genres.
2. The user enters a preferred genre.
3. The system compares the user's preference with each movie's genre.
4. Matching movies are displayed as recommendations.

## Technologies Used

- Python
- Lists
- Dictionaries
- Conditional statements
- For loop
- User input
